# SDR2HDR Desktop v1.2.1

Windows 离线 SDR 转 HDR10 工具，提供图形界面和命令行入口。

## 本次发布

- 四档画面编码：快速、标准、精细、画面无损。
- 画面无损档使用专用无损编码模式，导出后自动逐帧验证。
- 可选双声道虚拟环绕；已有 HDR 可直接保留视频轨道，只处理声音。
- 支持 10 秒试转、取消、导出检查和转换记录。
- 支持进度暂不可用及可选媒体数值缺失的处理。
- 提供使用指南、算法说明、集成测试和构建脚本。

## 下载与使用

下载并解压 Windows ZIP，运行 `SDR2HDR.exe`。FFmpeg 和 ffprobe 需单独准备，可放入程序旁的 `bin` 文件夹。

包内提供 `SHA256SUMS.txt` 供校验。

## 使用范围

画面无损仅指 HDR 处理完成后的 10-bit 4:2:0 视频编码，不保证音频无损，也不保证平台转码后无损。无损文件体积较大，部分播放器需要软件解码。

视频平台的接收和转码结果需要实际投稿验证。程序不会自动上传或发布视频。
