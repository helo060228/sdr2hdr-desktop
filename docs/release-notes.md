# SDR2HDR Desktop v1.5.2

Windows 离线 **SDR / 杜比视界（Dolby Vision）转 HDR10** 工具，支持三档 SDR 风格预设（影院均衡高光 750 nit / 柔和暗室保护 450 nit / 高对比原版·动漫）、Vulkan + GPU 色彩加速管线、停止并保留可播放片段、显卡硬件加速与杜比视界无损直剥。

## v1.5.2 本次更新

- **SDR 转 HDR10 细分为三档预设，默认升级为“影院均衡高光（推荐电影·750 nit）”**：
  - **影院均衡高光（推荐电影·750 nit，`balanced`，默认）**：针对 v1.5.0/1.5.1 中 `450 nit` 柔和模式“保住了额头细节与黑位但整体偏暗、极亮高光冲击力偏弱”的实拍对比反馈，新曲线把**暗部黑位继续锚定在深沉区间（~1.3 nits）**、将**中间调平滑拉回正常影院亮度（~71 nits）**、把**受光额头稳在约 220/750 nits（保留 3 倍以上 PQ 动态余量不发白过曝）**，同时把**灯光/反光峰值拉开到 750 nits**（`MaxCLL = 750 / MaxFALL = 260`），做到黑位、中间调、肤色高光细节与高光爆发力四者兼顾。
  - **柔和暗室保护（450 nit，`natural`）**：完整保留 v1.5.0/1.5.1 的温和 `450 nit` 保护曲线，适合全黑暗室观影。
  - **高对比风格（原版·动漫，`vivid`）**：完整保留 v1.4 及以前的高对比对数曲线，适合动漫与暗场景。
- 新增 **20 项完整真实 FFmpeg 集成测试**，验证三档风格的 GPU 着色器与 CPU 3D LUT 像素一致性、肤色零色偏、高光余量、显卡硬编与无损逐帧校验全部通过。

## v1.5.0 – v1.5.1 核心特性

- **Intel 核显 / 锐炫 (`hevc_qsv`) 10-bit ICQ 画质校准**（`19 / 16 / 14` + 自动探测 `extbrc/mbbrc`）与 **可选“NVENC 双遍分析 (Multipass)”开关**。
- **Vulkan 硬解 + `libplacebo` GPU 色彩管线加速**（支持 SDR 三档风格与杜比视界 Profile 5/8.4 还原）与 **“停止并保留”优雅封包可播放 `*_已转片段.mp4`**。
- **杜比视界（DV）转 HDR10**：Profile 8.1/7（含无容器矩阵标记的蓝光 MKV Remux）秒级无损直剥，Profile 5/8.4 Vulkan 硬解 + `libplacebo` 色彩还原重编码。

## 下载与使用

下载并解压 Windows ZIP，运行 `SDR2HDR.exe`。FFmpeg 和 ffprobe 需单独准备，可放入程序旁的 `bin` 文件夹。建议使用较新的完整 FFmpeg 构建（包含 `zscale`、`lut1d`、`lut3d`、`libx265`、`dovi_rpu`、`dovi_split`、`libplacebo` 及显卡编码器）。

包内提供 `SHA256SUMS.txt` 供校验。

## 使用范围

- 无论选择哪种风格，都不会凭空恢复原 SDR 片源已经剪裁或压缩丢失的高光细节。
- 仅含单一杜比视界流且无 HDR10 兼容层的 Profile 5 / Profile 8.4 片源必须经 `libplacebo` 色彩还原后重编码，无法像 Profile 8.1 / Profile 7 那样无损直剥；Profile 7 无损直剥保留原生 HDR10 基础层，不烘焙 FEL 增强层的额外亮度增量。
- 画面无损仅指重编码路径中 HDR 处理完成后的 10-bit 4:2:0 视频编码，不保证音频无损，也不保证平台转码后无损。QSV 与 AMF 不支持 10-bit HEVC 无损，“自动”模式会回退 CPU (`libx265`)。
- 视频平台的接收和转码结果需要实际投稿验证。程序不会自动上传或发布视频。
